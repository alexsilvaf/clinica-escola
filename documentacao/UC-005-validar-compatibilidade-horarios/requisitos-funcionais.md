# Requisitos funcionais do UC-005

| ID | Requisito | Classe | Prioridade | Status |
|---|---|---|---|---|
| RF-005.01 | O sistema deve localizar horários da turma, disciplina ou estágio no semestre ativo. | Confirmado | Must | Rascunho |
| RF-005.02 | O sistema deve filtrar horários pelo vínculo e disponibilidade do estudante. | Confirmado | Must | Rascunho |
| RF-005.03 | O sistema deve considerar disponibilidade de supervisor e clínica simultaneamente. | Confirmado | Must | Rascunho |
| RF-005.04 | O sistema deve considerar limites de supervisão e capacidade física. | Confirmado/Inferido | Must | Rascunho |
| RF-005.05 | O sistema deve bloquear estudante sem aptidão documental. | Confirmado | Must | Rascunho |
| RF-005.06 | O sistema deve revalidar a opção antes de confirmar a operação consumidora. | Inferido | Must | Rascunho |
