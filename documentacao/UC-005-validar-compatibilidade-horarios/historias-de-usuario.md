# Histórias de usuário do UC-005

## US-005.01 — Consultar horários elegíveis

> Como estudante apto, quero visualizar somente horários compatíveis para evitar inscrições inválidas.

- **Prioridade:** Must
- **Status:** Rascunho

## US-005.02 — Entender impedimento

> Como estudante, quero saber por que não posso acessar horários para corrigir uma pendência quando possível.

- **Prioridade:** Should
- **Status:** Rascunho

## US-005.03 — Revalidar seleção

> Como responsável pela clínica, quero que a seleção seja revalidada para impedir uso de uma disponibilidade já alterada.

- **Prioridade:** Must
- **Status:** Rascunho
