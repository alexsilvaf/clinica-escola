# Histórias de usuário do UC-006

[Início](../../README.md) · [Documentação](../README.md) · [UC-006](README.md) · Histórias de usuário

## US-006.01 — Configurar recursos

> Como responsável pela clínica, quero cadastrar ambientes e equipamentos para representar a estrutura disponível.

- **Prioridade:** `Must`
- **Status:** `Rascunho`

## US-006.02 — Configurar limites

> Como responsável, quero definir máximos simultâneos de atendimentos e estudantes para respeitar a operação da clínica.

- **Prioridade:** `Must`
- **Status:** `Rascunho`

## US-006.03 — Bloquear excesso

> Como instituição, quero impedir reservas acima de qualquer capacidade para evitar conflito físico.

- **Prioridade:** `Must`
- **Status:** `Rascunho`
