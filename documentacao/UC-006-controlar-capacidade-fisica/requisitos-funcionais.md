# Requisitos funcionais do UC-006

[Início](../../README.md) · [Documentação](../README.md) · [UC-006](README.md) · Requisitos funcionais

| ID          | Requisito                                                                           | Classe              | Prioridade | Status   |
| ----------- | ----------------------------------------------------------------------------------- | ------------------- | ---------- | -------- |
| `RF-006.01` | O sistema deve cadastrar clínicas, ambientes e consultórios/salas.                  | Confirmado          | Must       | Rascunho |
| `RF-006.02` | O sistema deve registrar equipamentos ou suas quantidades conforme modelo validado. | Confirmado/Inferido | Must       | Rascunho |
| `RF-006.03` | O sistema deve registrar máximos simultâneos de atendimento e estudantes.           | Confirmado          | Must       | Rascunho |
| `RF-006.04` | O sistema deve calcular a capacidade efetiva considerando todos os limites.         | Inferido            | Must       | Rascunho |
| `RF-006.05` | O sistema deve impedir operação que exceda qualquer capacidade aplicável.           | Inferido            | Must       | Rascunho |
| `RF-006.06` | O sistema deve permitir inativação ou bloqueio temporal de recurso.                 | Inferido            | Should     | Rascunho |
