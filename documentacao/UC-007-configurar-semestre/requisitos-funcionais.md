# Requisitos funcionais do UC-007

[Início](../../README.md) · [Documentação](../README.md) · [UC-007](README.md) · Requisitos funcionais

| ID          | Requisito                                                                                                               | Classe              | Prioridade | Status   |
| ----------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------- | -------- |
| `RF-007.01` | O sistema deve criar configuração identificada por ano/período e escopo institucional.                                  | Confirmado/Inferido | Must       | Rascunho |
| `RF-007.02` | O sistema deve associar estudantes, capacidades, horários, supervisores, limites, disciplinas, períodos e consultórios. | Confirmado          | Must       | Rascunho |
| `RF-007.03` | O sistema deve validar consistência antes da ativação.                                                                  | Inferido            | Must       | Rascunho |
| `RF-007.04` | O sistema deve ativar configuração válida para reger novos cálculos.                                                    | Inferido            | Must       | Rascunho |
| `RF-007.05` | O sistema deve preservar e permitir consulta autorizada ao histórico semestral.                                         | Inferido            | Must       | Rascunho |
| `RF-007.06` | O sistema deve auditar ativação e alterações relevantes.                                                                | Inferido            | Should     | Rascunho |
