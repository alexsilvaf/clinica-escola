# Histórias de usuário do UC-007

## US-007.01 — Criar configuração

> Como Master, quero criar a configuração do semestre para adaptar o sistema ao período letivo.

- **Prioridade:** Must
- **Status:** Rascunho

## US-007.02 — Validar configuração

> Como responsável institucional, quero identificar inconsistências antes da ativação para não publicar horários inválidos.

- **Prioridade:** Must
- **Status:** Rascunho

## US-007.03 — Ativar semestre

> Como Master, quero ativar uma configuração consistente para que ela passe a reger a operação.

- **Prioridade:** Must
- **Status:** Rascunho

## US-007.04 — Consultar histórico

> Como usuário autorizado, quero consultar o contexto de semestres anteriores para preservar rastreabilidade.

- **Prioridade:** Must
- **Status:** Rascunho
