# Histórias de usuário do UC-002

## US-002.01 — Enviar documento

> Como estudante, quero enviar documentos e acompanhar a situação para corrigir pendências antes de participar da clínica.

- **Prioridade:** Must
- **Status:** Rascunho

## US-002.02 — Analisar documento

> Como responsável autorizado, quero aprovar ou recusar um documento com justificativa para controlar a aptidão documental.

- **Prioridade:** Must
- **Status:** Rascunho

## US-002.03 — Bloquear estudante pendente

> Como responsável pela clínica, quero que estudantes com pendência sejam bloqueados automaticamente para evitar participação irregular.

- **Prioridade:** Must
- **Status:** Rascunho
