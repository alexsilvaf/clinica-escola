# Requisitos funcionais do UC-002

[Início](../../README.md) · [Documentação](../README.md) · [UC-002](README.md) · Requisitos funcionais

| ID          | Requisito                                                                                     | Classe     | Prioridade | Status   |
| ----------- | --------------------------------------------------------------------------------------------- | ---------- | ---------- | -------- |
| `RF-002.01` | O sistema deve permitir configurar documentos obrigatórios pelo contexto acadêmico aplicável. | Inferido   | Must       | Rascunho |
| `RF-002.02` | O sistema deve permitir ao estudante enviar digitalmente cada documento exigido.              | Confirmado | Must       | Rascunho |
| `RF-002.03` | O sistema deve exibir situações `Pendente`, `Em análise`, `Aprovado` e `Recusado`.            | Inferido   | Must       | Rascunho |
| `RF-002.04` | O sistema deve permitir a responsável autorizado aprovar ou recusar documento.                | Confirmado | Must       | Rascunho |
| `RF-002.05` | O sistema deve exigir orientação de correção ao recusar.                                      | Confirmado | Must       | Rascunho |
| `RF-002.06` | O sistema deve bloquear horários enquanto houver pendência obrigatória.                       | Confirmado | Must       | Rascunho |
| `RF-002.07` | O sistema deve preservar o histórico de envios e decisões.                                    | Inferido   | Must       | Rascunho |
