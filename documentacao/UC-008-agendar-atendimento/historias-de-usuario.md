# Histórias de usuário do UC-008

[Início](../../README.md) · [Documentação](../README.md) · [UC-008](README.md) · Histórias de usuário

## US-008.01 — Consultar horários

> Como pessoa da comunidade, quero consultar serviços e horários realmente disponíveis para escolher uma opção.

- **Prioridade:** `Must`
- **Status:** `Rascunho`

## US-008.02 — Criar agendamento

> Como pessoa da comunidade, quero reservar um horário para receber atendimento.

- **Prioridade:** `Must`
- **Status:** `Rascunho`

## US-008.03 — Confirmar

> Como pessoa agendada, quero confirmar meu comparecimento para manter a reserva.

- **Prioridade:** `Must`
- **Status:** `Rascunho`

## US-008.04 — Cancelar

> Como pessoa agendada, quero cancelar minha reserva para liberar o horário.

- **Prioridade:** `Must`
- **Status:** `Rascunho`
