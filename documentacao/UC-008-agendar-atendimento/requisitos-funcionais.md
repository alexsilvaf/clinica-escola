# Requisitos funcionais do UC-008

| ID | Requisito | Classe | Prioridade | Status |
|---|---|---|---|---|
| RF-008.01 | O sistema deve permitir consulta pública de serviços e horários elegíveis. | Confirmado | Must | Rascunho |
| RF-008.02 | O sistema deve coletar apenas dados mínimos definidos para o agendamento. | LGPD/Inferido | Must | Rascunho |
| RF-008.03 | O sistema deve revalidar recursos e criar a reserva atomicamente. | Confirmado/Inferido | Must | Rascunho |
| RF-008.04 | O sistema deve fornecer identificador não previsível e orientação de acesso. | Inferido | Must | Rascunho |
| RF-008.05 | O sistema deve confirmar agendamento elegível. | Confirmado | Must | Rascunho |
| RF-008.06 | O sistema deve cancelar agendamento elegível. | Confirmado | Must | Rascunho |
| RF-008.07 | O sistema deve atualizar capacidades após mudança de status conforme regra. | Inferido | Must | Rascunho |
