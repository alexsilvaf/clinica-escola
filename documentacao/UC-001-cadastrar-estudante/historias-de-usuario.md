# Histórias de usuário do UC-001

[Início](../../README.md) · [Documentação](../README.md) · [UC-001](README.md) · Histórias de usuário

## US-001.01 — Cadastrar estudante

> Como responsável acadêmico, quero cadastrar um estudante com seus vínculos para que ele possa participar das atividades da clínica-escola.

- **Prioridade:** `Must`
- **Status:** `Rascunho`
- **Valor:** formar a base de elegibilidade acadêmica.

## US-001.02 — Manter disponibilidade

> Como estudante, quero informar minha disponibilidade para que sejam considerados apenas horários em que eu possa participar.

- **Prioridade:** `Must`
- **Status:** `Rascunho`
- **Premissa:** ainda é necessário validar se o próprio estudante poderá editar esse dado.

## US-001.03 — Inativar estudante

> Como responsável autorizado, quero inativar um estudante sem apagar seu histórico para impedir novas alocações indevidas.

- **Prioridade:** `Must`
- **Status:** `Rascunho`
