# Requisitos funcionais do UC-001

| ID | Requisito | Classe | Prioridade | Status |
|---|---|---|---|---|
| RF-001.01 | O sistema deve permitir a usuário autorizado cadastrar e editar nome, matrícula, curso, período e contato do estudante. | Confirmado | Must | Rascunho |
| RF-001.02 | O sistema deve vincular o estudante a uma ou mais disciplinas ou estágios no semestre aplicável. | Confirmado | Must | Rascunho |
| RF-001.03 | O sistema deve registrar a disponibilidade do estudante. | Confirmado | Must | Rascunho |
| RF-001.04 | O sistema deve manter situação ativa ou inativa sem apagar o histórico acadêmico. | Inferido | Must | Rascunho |
| RF-001.05 | O sistema deve impedir duplicidade de matrícula no escopo institucional validado. | Inferido | Must | Rascunho |
| RF-001.06 | O sistema deve exibir a situação acadêmica e documental necessária ao cálculo de elegibilidade. | Inferido | Must | Rascunho |

Todo RF somente poderá ser concluído quando estiver ligado a uma história, regra, critério e teste.
