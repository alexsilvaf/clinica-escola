# Histórias de usuário do UC-009

## US-009.01 — Administrar usuários

> Como Master, quero cadastrar, editar, ativar e inativar usuários para controlar quem acessa o sistema.

- **Prioridade:** Must
- **Status:** Rascunho

## US-009.02 — Administrar permissões

> Como Master, quero atribuir papéis e permissões para aplicar o menor privilégio.

- **Prioridade:** Must
- **Status:** Rascunho

## US-009.03 — Manter catálogos

> Como Master, quero manter cursos, disciplinas, clínicas e ambientes para sustentar as configurações semestrais.

- **Prioridade:** Must
- **Status:** Rascunho

## US-009.04 — Consultar dados gerais

> Como Master, quero consultar dados gerais e auditoria autorizada para acompanhar a operação.

- **Prioridade:** Must
- **Status:** Rascunho
