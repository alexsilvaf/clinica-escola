# Requisitos funcionais do UC-009

[Início](../../README.md) · [Documentação](../README.md) · [UC-009](README.md) · Requisitos funcionais

| ID          | Requisito                                                                    | Classe              | Prioridade | Status   |
| ----------- | ---------------------------------------------------------------------------- | ------------------- | ---------- | -------- |
| `RF-009.01` | O sistema deve autenticar usuário interno antes de liberar função restrita.  | Confirmado          | Must       | Rascunho |
| `RF-009.02` | O sistema deve autorizar cada operação por papel e permissão no servidor.    | Confirmado/Inferido | Must       | Rascunho |
| `RF-009.03` | O sistema deve cadastrar, editar, ativar e inativar usuários.                | Confirmado/Inferido | Must       | Rascunho |
| `RF-009.04` | O sistema deve administrar papéis e permissões.                              | Confirmado          | Must       | Rascunho |
| `RF-009.05` | O sistema deve manter cursos, disciplinas, clínicas e ambientes.             | Confirmado          | Must       | Rascunho |
| `RF-009.06` | O sistema deve alterar configurações e capacidades preservando consistência. | Confirmado          | Must       | Rascunho |
| `RF-009.07` | O sistema deve permitir consulta autorizada a dados gerais.                  | Confirmado          | Must       | Rascunho |
| `RF-009.08` | O sistema deve registrar auditoria das operações sensíveis definidas.        | Inferido            | Must       | Rascunho |
