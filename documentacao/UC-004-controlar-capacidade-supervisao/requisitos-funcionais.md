# Requisitos funcionais do UC-004

| ID | Requisito | Classe | Prioridade | Status |
|---|---|---|---|---|
| RF-004.01 | O sistema deve calcular alocações simultâneas ativas por supervisor e intervalo. | Inferido | Must | Rascunho |
| RF-004.02 | O sistema deve calcular a capacidade restante a partir do limite vigente. | Inferido | Must | Rascunho |
| RF-004.03 | O sistema deve bloquear nova inscrição quando o limite for atingido. | Confirmado | Must | Rascunho |
| RF-004.04 | O sistema deve revalidar a capacidade ao confirmar a operação. | Inferido | Must | Rascunho |
| RF-004.05 | O sistema deve atualizar a capacidade quando uma alocação deixar de consumi-la. | Inferido | Must | Rascunho |
